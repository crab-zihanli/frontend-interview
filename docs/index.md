## 🧭 如何使用这个网站？

### 建议复习顺序和节奏

1. **先从 `javascript` 看起**
   每个章节都包含了知识点总结和手写题，建议先看知识点总结，理解原理，再尝试手写题。当所有章节都看完后，可以回过头来专门练习手写题部分。手写题部分有随机抽题功能，可以反复练习。《JavaScript 高级程序设计》（红宝书）是非常好的参考书籍，我经常用它来查漏补缺。

2. **计算机网络和浏览器原理**
   部分内容比较独立且有点枯燥，平时做项目中接触较少，建议先大致理解一遍，再集中精力背诵巩固，面试中这两部分很常考。个人的阅读书籍有《网络是怎样连接的》这本没有那么专业的书籍，因为是非科班所以读太晦涩的有点读不下去，这本用来大致理解网络的运行原理还是很有帮助的。

3. **前端框架**
   部分内容更新较快，对于框架了解它们的核心原理和常见面试题就行，可以结合官方文档和社区资源进行学习。我自己的框架用 `Vue` 比较多，所以 `Vue` 部分内容会相对详细一些。框架还有个问题就是可能会出场景题，所以这里也列出了一些常见场景题供大家参考。

4. **数据结构与算法**
   大厂面试会考察这部分内容，建议每天练上几道。说实话这部分内容我个人准备得不够充分，我的思路是先按照章节看一遍，理解基本概念和常见题型，然后反复刷，基本就是背题了。至于刷多少题，见仁见智？差不多高频的前100道的简单和中等题目得能说出思路和代码实现（如果是去大厂）。
   - **书籍**：《学习javascript数据结构与算法》语言通俗易懂，适合快速入门了解基本的数据结构和算法思想。
   - **网站**：[代码随想录](https://www.programmercarl.com/%E6%95%B0%E7%BB%84%E7%90%86%E8%AE%BA%E5%9F%BA%E7%A1%80.html)是按照不同的专题来讲解数据结构和算法的，内容比较系统且有代码示例。[CodeTop](https://codetop.cc/home) 是一个按照考察频率来整理题目的平台，适合刷题，选择前端方向即可。

5. **其它知识点**
   大家根据自己的薄弱环节进行针对性复习，尤其是自己项目中遇到的，一定要深入去研究理解。

::: info 前端面试考察点
这部分就是想告诉大家，一般提问的考察方向，让大家知道自己面试会遇到什么，针对性复习，不然看着一堆知识点，还没开始就头大了。

1. **前端基础知识和原理**：基本就是这个网站的大部分内容，JavaScript、浏览器原理、网络协议、HTML/CSS等，感觉一面或者没有实习的时候会问这个多，要是最基础的什么JS的数据类型有哪些都说不对，很影响评价。
2. **项目经验和实战能力**：面试官会问你之前做过什么项目，遇到过什么问题，怎么解决的，考察你的实战经验和解决问题的能力。可能也会深入拷打技术细节，所以一定要对自己项目中的技术点有深入理解。
3. **数据结构与算法**：尤其是大厂面试会考察这部分内容，主要考察你的逻辑思维能力和编程能力。
4. **手写题和场景题**：在前端还有两种类型需要写代码的题目，但不算是算法题，所以不止是大厂考，很多公司都会考察这部分内容。手写题基本是让你写个涉及到原理的函数（见手写题模块），场景题就是给你一个实际的场景，让你设计解决方案，常见就是todoList之类的。
:::

::: tip 面试和找工作心态
投出去已读不回的简历和总是被刷掉的面试是很让人沮丧的事情，我个人的经验是：

1. **保持积极心态**：找工作总有一种被选择的感觉，尤其是总被刷掉或否定，但不要因为这个就去否定自己，人是在不断变化成长的，以及也许只是跟这个岗位本来就不合适罢了。包括在面试的时候，即便遇到不会的问题，坦率承认，并且跟面试官保持良好沟通，展现出积极学习的态度，这样也会给面试官留下好印象。
2. **持续学习和提升**：面试过程中遇到的问题和不足，都是提升自己的机会。不断学习新的知识和技能，提升自己的竞争力。
3. **多练习和准备**：可以在牛客看看别人po出来的面试题，练习回答问题和写代码。
:::
